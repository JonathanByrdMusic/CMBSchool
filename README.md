# CMBSchool

Interactive public-to-undergraduate exploration of the science behind the cosmic microwave background.

## About

**CMB School** is an interactive web-based introduction to the importance and utility of cosmic microwave background radiation as a scientific resource. Inspired by **Simons Obervatory's** CMB Data School, the site bridges public-facing astronomy outreach and the quantitative tools used in undergraduate- and graduate-level CMB analysis.

## Scientific Data

The site uses image, instrument-response, bandpass, and calibrated-intensity products derived from or associated with:

- Planck / ESA
- Haslam 408 MHz all-sky survey and the Remazeilles et al. reprocessing
- WISE
- IRAS / IRIS
- Digitized Sky Survey (DSS / STScI)
- Pioneer 10/11 Imaging Photopolarimeter
- GALEX
- ROSAT All-Sky Survey
- Fermi Large Area Telescope (Fermi-LAT)

Pioneer 10/11 IPP measurements provide a calibrated visible-light reference for a relative intensity comparison.
